# Die Herren der Rench

Browserbasiertes 2D-RPG – Build 01: Map Engine.

## MAP1

**OBERKIRCH ZENTRUM**  
10.000 × 6.667 px

## Steuerung

- **WASD / Pfeiltasten** – Kamera bewegen
- **Maus ziehen** – Karte bewegen
- **Mausrad / + / -** – zwischen vier festen Zoomstufen wechseln

Zoom 0 zeigt die vollständige Karte. Zoom 1–3 führen zunehmend näher in die 10K-Spielwelt.

## GitHub Pages

Das Projekt benötigt keinen Build-Prozess und keine Abhängigkeiten. Repository hochladen und GitHub Pages für den Repository-Root aktivieren.


Die 10K-Karte wird verlustbehaftet als hochwertiges WebP gespeichert, damit der komplette GitHub-Build unter 25 MB bleibt.
