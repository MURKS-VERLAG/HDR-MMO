# Die Herren der Rench – Build 09: Combat + Block FIX

Dieser Build enthält wieder das vollständige Kampfsystem und ergänzt STRG-Blocken.

## LEERTASTE – Angriff

### Rechts
RIGHT 1 400 ms → BASE 100 ms → RIGHT 2 400 ms → BASE 100 ms → RIGHT 3 400 ms → BASE 100 ms → FINISH 400 ms → BASE 100 ms → Wiederholung solange SPACE gehalten wird.

### Links
Exakt dieselbe Sequenz, technisch horizontal gespiegelt.

### Nach unten / S
Nach S bleibt die Combat-Base-Haltung stehen.

DOWN-Sequenz:
BASE 100 ms → DOWN 1 400 ms → BASE 100 ms → DOWN 2 400 ms → BASE 100 ms → FINISH 400 ms → BASE 100 ms → Wiederholung solange SPACE gehalten wird.

WICHTIG: Der bisherige Anhang 7 wird NICHT mehr als DOWN-Angriff verwendet.

## STRG – Blocken

STRG gedrückt halten = Blockbild bleibt dauerhaft sichtbar.
Bei Blickrichtung links wird das Blockbild technisch gespiegelt.
Während Blocken sind Bewegung und Angriff gesperrt.
Beim Loslassen von STRG kehrt der Charakter in die passende Ruhehaltung zurück.

## Bestehendes System
Map, Zoom, Kamera, WASD, S-Laufanimation, Stand links/rechts und alle bisherigen Bewegungsregeln bleiben erhalten.
